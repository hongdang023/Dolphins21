Xuất & Sao Lưu Dữ Liệu Hồ Sơ

Dữ liệu hoàn toàn thuộc quyền sở hữu của bạn. Bạn có thể xuất file JSON để sao lưu hoặc chuyển đổi sang thiết bị khác.

1. Sao Lưu Toàn Bộ Dữ Liệu (Backup JSON)

Bao gồm: Thông tin Profile, toàn bộ điểm đánh giá (Ratings), Snapshots, Mục tiêu SMART và Evidence Vault.

2. Khôi Phục Dữ Liệu (Import JSON)

Tải lên file JSON đã sao lưu từ trước để khôi phục trạng thái làm việc.
